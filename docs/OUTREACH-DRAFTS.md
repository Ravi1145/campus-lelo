## 4. Quora / Reddit answers (answer the question first, link second)

Question type: "Is CAT mandatory for an MBA in Dehradun?"

Draft:
Not for the two colleges I checked. Graphic Era's MBA page lists CAT, MAT, XAT, CMAT and GMAT as well as its
own entrance test. UPES lists its own test (UPESMET) alongside national exams. Both then hold an interview.
IIM Kashipur is the exception, and it is in Kashipur, not Dehradun. It needs CAT. Check each college's own
page for the current year. I work on CampusLelo, where I keep a checked list with the source pages:
https://campuslelo.com/mba-colleges-in-dehradun

Question type: "How does MBA admission work in UP through CUET PG / UPTAC?"

Draft:
UPTAC lists MBA and MCA against CUET PG as the entrance exam, and its portal has an Information Brochure
2026, a counselling procedure and a schedule. Dates and fees get quoted differently on coaching sites, so
read the brochure for eligibility, domicile, fees and rounds. I work on CampusLelo and wrote up what the
portal shows and what to check: https://campuslelo.com/uptac-mba-counselling

Question type: "What is the IIM Kashipur CAT cutoff?"

Draft:
IIM Kashipur publishes minimum CAT percentiles used to pick candidates for the interview. For CAT 2024 the
General minimums were 75 in each section and 95 overall. For 2026-28 it ran shortlisting through the Joint
Admission Process, so check the JAP portal for that year's category figures. I work on CampusLelo, where
the table and sources are here: https://campuslelo.com/mba-cutoff-uttarakhand
