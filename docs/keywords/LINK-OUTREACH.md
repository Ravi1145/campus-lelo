# Getting links to campuslelo.com (the main ranking lever)

Search Console (17 Oct 2026) shows average position ~68 for a site that is about a week old in Google.
Page edits will not close that gap. Links from real education sites will.

## What to offer (only things no one else has)
- NIRF 2025 management rank tables by city/state: /best-mba-colleges-in-india and the city pages
- Which exam each MBA/PGDM programme accepts, checked against official pages: /mba-exam-acceptance
- Published cut-offs with their source: /fms-delhi-cat-cutoff, /iift-cat-cutoff, /mba-cutoff-delhi-ncr
- MBA vs PGDM explained, with Hindi version: /mba-vs-pgdm, /mba-kya-hai

## Where to share (no purchased links)
1. MBA aspirant communities: Telegram/WhatsApp CAT, XAT, CMAT groups; Reddit r/CATpreparation, r/MBA_India. Answer a real question and link the table. Read each group's rules first.
2. Quora and Careers360/Shiksha Q&A: answer "which exams does X accept" with the sourced table and link it.
3. YouTube MBA-prep creators: send one useful table, ask if they want to cite it in a video description.
4. College student blogs, alumni groups, local coaching institutes in Delhi NCR/Noida/Dehradun/Lucknow.
5. Your own profiles: LinkedIn page, YouTube, Instagram, Google Business Profile, Facebook page. Same name "CampusLelo", link to campuslelo.com.

## Short pitch (edit before sending)
Subject: Checked table of which exams each Delhi NCR MBA/PGDM accepts

Hi <name>, I run CampusLelo. We checked the admission pages of 26 MBA/PGDM programmes and listed
which entrance exams each accepts, with the source and date: <link>. Free to use. If it helps your
readers, a link or mention would be appreciated. If anything is out of date, tell me and I will fix it.

## Do not
- Buy links or join link exchanges. It can get the site demoted.
- Copy the collegepune.com content.
- Spam the same link in many groups.
