# 100 lead keywords for MBA and PGDM admissions: Delhi first, then NCR and Uttarakhand

Built 27 Oct 2026 from the 8,800-keyword autocomplete harvest (`mba-keywords.csv`) plus the queries in the Search Console export of 27 Oct.

## What the columns mean (and do not mean)

- `lead_score`: our own score = search intent (admission and without-exam searches score highest) + Delhi/NCR/Uttarakhand focus + admission words + autocomplete prominence + Search Console impressions. Higher means closer to a student ready to apply.
- `autocomplete_signal` (0-13) is how prominent the phrase is in Google autocomplete. It ranks phrases against each other. It is **not** monthly search volume. No SEO tool is connected, so real volume and difficulty are unknown.
- GSC columns show what Search Console reported for the exact phrase in the export; blank if it did not appear.
- Fees, placements, packages, online/distance and other-city phrases are left out on purpose: we hold no sourced data for them.
- "Direct admission" and "without entrance exam" phrases map to the without-CAT page, which explains honestly that these institutes still need an exam score. We do not promise seats without an exam.

Tier A = build and push first (ranks 1-30). Tier B = next (31-65). Tier C = long tail (66-100).
